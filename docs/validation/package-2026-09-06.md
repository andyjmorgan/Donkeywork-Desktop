## Not yet validated

No package services were installed/activated on any live host. No desktop,
module, firewall, repository, SELinux or boot settings were changed. The package
unit lifecycle and reboot still need a controlled migration from minigpu's
transient pilot. Its working capture/input behaviour does not prove those new
units have passed end-to-end validation.

Rocky needs its explicitly selected private encoder and target ABI/SELinux
validation. Spark needs a native ARM64 build; KMS and X11 profiles are view-only.
VKMS full control remains the GNOME/Mutter 1080p pilot, not generic Wayland.
No authentication/public exposure, terminal UI, or dynamic resolution selector
is added by packaging.

Next: preserve the existing minigpu pilot definitions, migrate only its task
units to the package target, verify display/input/login recovery, then schedule
boot acceptance before rolling out the same version to another machine.
